# STM32 CAT14

## MQTT Client Publishing & Node-RED Integration

This experiment demonstrates MQTT message publishing from an STM32 microcontroller through an ESP8266 Wi-Fi module. A Node-RED MQTT subscriber can be configured to receive the published messages.
